Modern Web Guidanceとは？

AIコーディングエージェントが古いCSS・JavaScriptを生成しがちな問題を、現在のWeb標準、ブラウザ対応状況、実務的なガイドによって改善するGoogle公式スキル。

30秒でわかる答え

Modern Web Guidanceは、CodexなどのAIエージェントへモダンなWeb開発知識を必要なときだけ渡すスキルです。新しい機能を無条件に使わせるのではなく、Baselineによるブラウザ対応状況やフォールバックも考慮して提案させます。

元記事が伝えていること

AIへフロントエンド実装を頼むと、現在はブラウザ標準機能だけで簡潔に実装できる場面でも、古いパターンや大量のJavaScriptを選ぶことがあります。Modern Web Guidanceは、その問題を解決するためにWebプラットフォームの専門知識をAIのコンテキストへ注入します。

なぜAIは古いコードを書くのか

LLMの学習データには、長年蓄積されたレガシーコードが大量に含まれます。モデルが新しいAPIの存在を知っていても、実運用で正しく使うための実装パターンが不足し、古い多数派の書き方へ戻ることがあります。

Baselineとの連携

新しいWeb機能を採用する際には、対象ブラウザで安全に利用できるかが問題になります。Modern Web Guidanceは、主要ブラウザの対応状況を示すBaselineのデータを利用し、プロジェクトの対応方針に応じて機能やフォールバックを提案します。

重要なのは「常に最新機能を使う」ことではなく、ブラウザ対応、保守性、既存実装との相性を考えて選択できる点です。

仕組み: searchとretrieve

AIエージェントがフロントエンドの依頼を受けると、主に2段階で必要なガイドを取得します。

# 関連ガイドを検索
npx modern-web-guidance@latest search "animate a dialog modal backdrop"

# 選んだガイドの詳細を取得
npx modern-web-guidance@latest retrieve "animate-to-from-top-layer"
  1. searchが依頼に近いガイドを類似度付きで返す。
  2. retrieveが選択されたガイドの実装方法と対応状況を返す。
  3. AIエージェントが取得した情報を使って実装またはレビューする。

元記事によると、検索はローカルのTensorFlow.jsで動作し、APIキーや検索時のネットワーク通信を必要としません。

導入方法

npx modern-web-guidance@latest install

対話形式のウィザードが起動し、Codex、Claude Code、Cursorなど、利用するエージェントに合わせてスキルを配置します。導入後に自動発動しない場合は、「Modern Web Guidanceを使ってレビューして」のように明示します。

記事内で紹介された効果

Google公式の評価では、Claude Opus 4.7へ75件の曖昧なWeb開発タスクを依頼し、正しくモダンに実装できた割合が、スキルなしの約52%からスキルありの85%へ改善したと紹介されています。

また、元記事の筆者が自身のポートフォリオを監査した結果、次のように整理できたとしています。

  • 採用済み: oklch()、:has()、Subgridなどを確認。
  • 改善候補: テーマ切り替え時のちらつき対策、font-size-adjustなどを提案。
  • 見送り: 過去の経緯や既存サイトとの相性を考慮し、採用しない案も理由付きで整理。

実務での使い方

新規実装

Modern Web Guidanceを使い、アクセシブルなダイアログを実装して。
対応ブラウザとフォールバックも説明して。

既存サイトの監査

このリポジトリをModern Web Guidanceで監査して。
提案を「採用推奨・条件付き・見送り」に分類し、
アクセシビリティとパフォーマンスを優先して。

導入判断

この実装をPopover APIへ変更する利点とリスクを調査して。
対象ブラウザ、フォールバック、削減できるコード量を比較して。

注意点

  • プレビューリリースのため、内容や導入方法が変わる可能性がある。
  • Baseline対応だけで採用を決めず、自社の対象ブラウザと利用者環境を確認する。
  • 新機能への置き換えが、必ずしも既存プロジェクトの保守性を上げるとは限らない。
  • 生成されたコードは、アクセシビリティ、性能、セキュリティ、実ブラウザでの挙動を人間が確認する。
  • 既存フレームワークやデザインシステムの方針と衝突しないか確認する。
記事の結論

Modern Web Guidanceの価値は、最新技術を闇雲に使わせることではありません。AIが古い実装へ流れるのを防ぎ、現在のWeb標準を採用するか、フォールバックするか、見送るかを判断する材料を与えることです。
